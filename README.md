# DGRec_numerics
Data of the paper "Computational Design of Optimal Sequences for Targeted Hypermutagenesis Using Recombination-Coupled Diversity-Generating Retroelements" and code for training of the classifiers (see Fig4 folder) + LSTM (see Fig3 folder), as well as for plots.

The code contained in 'Making_the_libraries.ipynb' should be run first to generate from the files in "data" the dataframe "Summary_all.csv"  that contains the DGRec information about all sequences accross the different libraries. This file is then used in the different codes present in all the folders.

Each folder contains the code for generating the corresponding plots in the paper.
